# Tiếp cận bài toán

## Đề bài

Write a program that automatically guesses random words. Connect to an API that plays a Wordle-like puzzle. You can
find the API documentation here: https://wordle.votee.dev:8000/redoc

## Phân tích yêu cầu

### Problem 1: Hiểu cách chơi Wordle

- Wordle là trò chơi đoán từ gồm 5 chữ cái
- Người chơi có 6 lần đoán để tìm ra từ bí mật
- Mỗi lần đoán phải là từ có nghĩa và nằm trong danh sách các từ được phép đoán
- Kết quả đoán được hiển thị bằng màu sắc: xanh lá cây (đúng vị trí), vàng (đúng từ nhưng sai vị trí), xám (sai)

### Problem 2: Kết nối với API

Kết nối với API để lấy thông tin về từ cần đoán. Tài liệu API tại: https://wordle.votee.dev:8000/redoc

#### Phân tích tài liệu API

Tài liệu API gồm có 3 API:

- API kiểm tra đáp án đoán từ mỗi ngày
- API kiểm tra đáp án đoán từ ngẫu nhiên
- API tạo từ cần đoán và kiểm tra đáp án

Kết quả API trả về dạng JSON có cấu trúc như sau:

- Kết quả trả về là một mảng 5 items. Mỗi item là một object chứa dữ liệu của word đang đoán. Mỗi object item sẽ chứa dữ liệu sau:
  - Vị trí word tương ứng từ 1-5. Key là "slot" và value từ 0-4
  - Word được dự đoán. Key là "guess"
  - Kết quả dự đoán. Key là "result" và value là các trạng thái "absent" là word không có trong từ, "correct" là word có trong từ và đúng vị trí, "present" là word có trong từ và không đúng vị trí

```JSON
[
    {
        "slot": 0,
        "guess": "string",
        "result": "absent"
    },
    // ...
]
```

### Problem 3: Thuật toán tự động đoán từ

Thuật toán đoán từ cần tuân theo các quy tắc của trò chơi như sau:

- Từ đoán gồm 5 chữ cái
- Từ đoán phải là từ có nghĩa
- Từ đoán phải nằm trong danh sách các từ được phép đoán
- Từ đoán phải thỏa mãn các điều kiện của trò chơi

#### Ý tưởng thực hiện thuật toán

1. Khởi đầu chiến lược

Lập trình để hệ thống luôn đoán từ đầu tiên chứa nhiều nguyên âm và phụ âm phổ biến

2. Phân tích phản hồi

Đọc dữ liệu trả về từ API của Votee sau mỗi lần đoán (Trạng thái: absent, correct, present)

3. Lọc tập dữ liệu

- "correct": Giữ lại các từ có chữ cái này ở đúng vị trí tương ứng.
- "present": Giữ lại các từ có chứa chữ cái này, nhưng loại bỏ các từ có chữ cái này ở vị trí hiện tại.
- "absent": Loại bỏ toàn bộ các từ chứa chữ cái này ra khỏi danh sách.

4. Quyết định

Chọn từ ngẫu nhiên (hoặc tối ưu theo tần suất chữ cái) từ danh sách vừa lọc và tiếp tục gửi API cho đến khi thắng

#### Pseudou-code

```pseudocode
current_guess = "CRANE" // Từ khởi đầu

result = HTTP_GET(https://wordle.votee.dev:8000/daily?guess={{current_guess}}) // Or another API in [API Documentation](https://wordle.votee.dev:8000/redoc)

while CheckResult(result) is not correct:
  absent_slot = [1, 2] // Example word is absent

  current_guess = ChooseGuessWord(current_guess, absent_slot) // Replace absent_slot to another word

  result = HTTP_GET(https://wordle.votee.dev:8000/daily?guess={{current_guess}})

print(current_guess)
```

### Problem 4: Trực quan hoá quá trình đoán từ

Trực quan hoá quá trình đoán từ bao gồm:

- Hiển thị từ đoán
- Hiển thị kết quả đoán
- Hiển thị số lần đoán

Giao diện hiển thị dựa vào [mẫu thiết kế này](https://share.google/e8P2quV3dlGd7UcF3).
Mẫu thiết kế sẽ lược bỏ các phần gồm có:

- Title/Navigation
- Keyboard

Bổ sung thêm các chế độ điều khiển

- Chọn chế độ đoán: Daily, Random, Selected
- Nút bắt đầu đoán từ
- Nút đoán lại từ
- Với chế độ Selected, sẽ có input ở trên để người dùng nhập từ cần đoán

Kiểm thử chương trình bao gồm:
